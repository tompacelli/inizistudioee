# Inizi 2027 website
Static site: upload the folder contents to the web root. English at /, Estonian at /et/.
Pages: index, work, services, studio, contact, privacy (cookie policy), 404.
Security headers: `_headers` (Netlify/Cloudflare Pages format; on other hosts copy them into server config). The CSP is also set via <meta>.

## Editing content (single source)
- `data/projects.json` — the 9 projects. Used by the Work page (cubes + project windows) and by the Home page ("Recent projects": the projects with `"featured": true`, first three). Edit once, run `python3 build_site.py`, both pages update.
- `data/clients.json` — client logo slots on the Home page (drop a white logo into `assets/img/clients/`, set `"logo"`).
- `data/reviews.json` — client comments on the Home page.

## Build and form
- Pages are generated by `tools/build_site.py` from `data/*.json`; the generated HTML is committed, so hosting needs no build step.
- Contact form: `js/form.js` posts to Web3Forms; the public access key is `FORM_KEY` in `tools/build_site.py`.
- Hosting on GitHub Pages ignores `_headers`; Cloudflare Pages / Netlify apply it.
